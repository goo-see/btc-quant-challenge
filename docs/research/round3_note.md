## Part C — Interpretation (written AFTER seeing Part B; does not alter Part A criteria)
1. **Gate**: all seven pass the pre-registered gate on the 9Y walk-forward. The gate is therefore
   not discriminating in this family — every fixed-parameter variant of the D rule set survives.
   Ranking must come from the pairwise reads, not from PASS/REVIEW/REJECT.
2. **Timeframe effect at 5d (D0 → D1 → D2)**: shortening the evaluation TF monotonically lowers
   OOS return (+226% → +124% → +80%), PF (4.06 → 2.78 → 1.97) and expectancy (₩1,172 → ₩530 →
   ₩264), while raising trades (105 → 160 → 236), fees (₩3.3k → ₩4.9k → ₩7.1k) and the
   fake-breakout share (21% → 38% → 50%). MDD stays similar (6.6–7.5%). 1h evaluation also drops
   profitable windows to 9/15. The reaction-speed gain is small at 5d (D1 median lead 0h) — most D1
   entries are the same swing a few hours earlier, plus 51 extra trades that D0 never took.
3. **Horizon effect at 2h (D1 → D3 → D5)**: OOS return is flat (+124% / +119% / +123%) but PF falls
   (2.78 → 2.21 → 2.01), MDD rises (6.6% → 9.4% → 7.6%), trades and fees rise, Recent 2Y decays
   (+10.3% → +8.2% → +6.1%) and 2026 YTD is negative for all three. Shorter horizons buy earlier
   (median lead 4h → 18h) but the extra entries are mostly fake breakouts (41–49%).
4. **Horizon effect at 1h (D2 → D4 → D6)**: same shape, weaker level: return ≈ +78–80% regardless
   of horizon, PF 1.97 → 1.75 → 1.63, fake breakouts 50% → 57%, fees up to ₩10.3k (3× D0). The
   earliest entries (D6 median 38h before D0) do not translate into return.
5. **Is faster better?** Historically, no. Every faster variant captures the same trends as D0
   (97–100% of D0 entries matched) but pays for the earlier entry with many more false entries;
   D0's edge is the filter, not the speed. The only dimension where a variant beats D0 is OOS MDD
   (D1 6.59% vs 7.23%, D2 recent-2Y MDD 2.8% vs 3.7%) — with roughly half the return.
6. **Caveat on D0's "OOS"**: D0's frozen parameters were chosen from the Round 2 walk-forward on
   this same dataset, so its fixed-parameter WF here is not truly out-of-sample (its Round 2
   selected-per-window OOS was +200% / 6.72% / 3.45 / 119). D1–D6 parameters are scaled copies of
   D0's, not fitted; the comparison is fair in the sense that none was optimised in Round 3, but
   D0 carries a selection advantage. This does not change the direction of any pairwise finding.
7. **Classification (next-round candidate status only)** — pre-registered gate → all PASS;
   interpretation ranks them: **D1** is the only variant worth carrying (same 13/15 windows, lower
   OOS MDD, PF 2.78, 160 trades, cost-robust) as a "robust, slightly faster" alternative;
   **D3/D5** are fast-entry candidates only (same return as D1, worse PF/MDD/recent decay);
   **D2/D4/D6** (1h) are not attractive on any robustness axis (9/15 windows, PF < 2, ≥ 50%
   fake breakouts, 2–3× fees).

## Limitations
- 1h base resolution for intrabar stops in the historical runs vs 1m in the forward shadow.
- D0 selection advantage (item 6); no parameter-neighbourhood stability by design (fixed params).
- Fixed ₩30,000 cap makes returns sub-linear in equity; fee/slippage assumptions are constants.
- The real D0 trader's staged warm-up drops the last 1h-stage day (see round3-report §D0 finding);
  the shadow D0 replica uses the full history, so its EMA100 differs from the live D0 by ≈0.07%.
